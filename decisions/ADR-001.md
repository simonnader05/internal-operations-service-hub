# ADR-001: Use One Service Hub Agent

## Status

Accepted

## Context

Employees need one central place to ask HR and IT questions and submit requests.

Using separate HR and IT agents would require employees to decide which agent to use before asking for help.

## Decision

The product will use one Service Hub Agent for both HR and IT services.

The agent will:

- Understand the employee's question.
- Provide available information and guidance.
- Help create a request when needed.
- Identify whether the request belongs to HR or IT.
- Route the request to the correct team.
- Show request status and updates.

The agent will not make final approval decisions.

## Consequences

Using one agent gives employees a simpler entry point and allows HR and IT requests to follow one shared request-management process.

However, the agent must correctly identify HR and IT topics,follow routing rules, and protect sensitive information.
